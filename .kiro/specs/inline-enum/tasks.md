# Implementation Plan

## Task Format Template

Use whichever pattern fits the work breakdown:

### Major task only
- [ ] {{NUMBER}}. {{TASK_DESCRIPTION}}{{PARALLEL_MARK}}
  - {{DETAIL_ITEM_1}} *(Include details only when needed. If the task stands alone, omit bullet items.)*
  - _Requirements: {{REQUIREMENT_IDS}}_

### Major + Sub-task structure
- [ ] {{MAJOR_NUMBER}}. {{MAJOR_TASK_SUMMARY}}
- [ ] {{MAJOR_NUMBER}}.{{SUB_NUMBER}} {{SUB_TASK_DESCRIPTION}}{{SUB_PARALLEL_MARK}}
  - {{DETAIL_ITEM_1}}
  - {{DETAIL_ITEM_2}}
  - _Requirements: {{REQUIREMENT_IDS}}_ *(IDs only; do not add descriptions or parentheses.)*

> **Parallel marker**: Append ` (P)` only to tasks that can be executed in parallel. Omit the marker when running in `--sequential` mode.
>
> **Optional test coverage**: When a sub-task is deferrable test work tied to acceptance criteria, mark the checkbox as `- [ ]*` and explain the referenced requirements in the detail bullets.

- [x] 1. String literal union の検出機能を実装する
- [x] 1.1 フィールド型における string literal union を検出し、インライン enum として認識する機能を追加する
  - string literal のみで構成される union 型をインライン enum として識別する
  - 各 literal 値から enum メンバー情報を抽出し、TSTypeReference に付加する
  - null を含む union の場合は null を除外し、nullable フラグを設定する
  - _Requirements: 1.1, 1.3_

- [x] 1.2 配列型の要素として使用される string literal union を正しく検出する
  - 配列要素の型解析時にインライン enum 検出ロジックを適用する
  - nullable な配列要素（`("a" | "b" | null)[]`）を適切に処理する
  - _Requirements: 4.1, 4.2_

- [x] 2. スキーマ外 TypeScript enum の検出機能を実装する
- [x] 2.1 (P) knownTypeNames に含まれない TypeScript enum 参照を検出する
  - フィールド型として参照される enum がスキーマ外定義かどうかを判定する
  - knownTypeNames に含まれる enum は従来通り参照型として扱う
  - _Requirements: 2.1, 2.3_

- [x] 2.2 (P) 検出したスキーマ外 enum のメンバー情報と symbol を抽出する
  - TypeScript enum の各メンバー値を取得する
  - 重複排除のために enum symbol を TSTypeReference に保持する
  - _Requirements: 2.1, 5.2_

- [x] 3. リゾルバ引数におけるインライン enum 検出を実装する
- [x] 3.1 Query/Mutation リゾルバの引数型からインライン enum を検出する
  - defineQuery/defineMutation の Args 型パラメータを解析する
  - 引数型に含まれる string literal union およびスキーマ外 enum を検出する
  - _Requirements: 1.2, 2.2_

- [x] 3.2 フィールドリゾルバの引数型からインライン enum を検出する
  - defineField の Args 型パラメータを解析する
  - ネストした引数オブジェクト内のインライン enum も検出する
  - _Requirements: 1.2, 2.2_

- [x] 4. インライン enum の収集と命名機能を実装する
- [x] 4.1 抽出された型情報からインライン enum を収集する
  - ExtractedTypeInfo の各フィールドからインライン enum を走査する
  - コンテキスト情報（親型名、フィールド名）を保持する
  - _Requirements: 3.1, 3.2_

- [x] 4.2 リゾルバ結果からインライン enum を収集する
  - Query/Mutation/Field リゾルバの引数からインライン enum を走査する
  - リゾルバ種別に応じたコンテキスト情報を保持する
  - _Requirements: 3.3, 3.4_

- [x] 4.3 収集したインライン enum に対して命名規則に基づく型名を生成する
  - Object フィールドは `{ParentTypeName}{PascalCaseFieldName}` 形式を適用する
  - Input フィールドは `{ParentTypeNameWithoutInputSuffix}{PascalCaseFieldName}Input` 形式を適用する
  - Query/Mutation 引数は `{PascalCaseFieldName}{PascalCaseArgName}Input` 形式を適用する
  - Field リゾルバ引数は `{ParentTypeName}{PascalCaseFieldName}{PascalCaseArgName}Input` 形式を適用する
  - _Requirements: 3.1, 3.2, 3.3, 3.4_

- [x] 5. GraphQL enum 型の自動生成機能を実装する
- [x] 5.1 インライン enum から AutoGeneratedType（kind: Enum）を生成する
  - enum 値を SCREAMING_SNAKE_CASE に変換して出力する
  - 変換前後の値マッピング情報を保持する
  - _Requirements: 1.4, 2.4_

- [x] 5.2 同一スキーマ外 TypeScript enum の複数参照を単一の GraphQL enum 型にマージする
  - ExternalEnumRegistry で enum symbol から生成型名へのマッピングを管理する
  - 同一 symbol を持つ参照は同じ型名を再利用する
  - _Requirements: 5.2_

- [x] 5.3 同一 string literal union の独立した enum 型生成を確認する
  - 同じメンバーセットを持つ string literal union でも、出現箇所ごとに独立した型を生成する
  - _Requirements: 5.1_

- [x] 6. 型名競合検証と TSDoc 反映を実装する
- [x] 6.1 (P) 生成された enum 型名と既存型名の競合を検証する
  - 自動生成 enum 型名が既存の型定義と衝突する場合にエラーを報告する
  - 複数のインライン enum から同一型名が生成される場合にエラーを報告する
  - _Requirements: 5.3_

- [x] 6.2 (P) スキーマ外 TypeScript enum の TSDoc コメントを GraphQL description として反映する
  - enum 型本体の TSDoc を description に設定する
  - 各 enum メンバーの TSDoc を値の description に設定する
  - `@deprecated` タグを GraphQL の deprecated ディレクティブに変換する
  - _Requirements: 6.1, 6.2, 6.3_

- [x] 7. 生成結果をパイプラインに統合する
- [x] 7.1 元の型参照を生成された enum 型名で更新する
  - ExtractedTypeInfo 内のフィールド型参照を更新する
  - ResolversResult 内の引数型参照を更新する
  - _Requirements: 1.1, 1.2, 2.1, 2.2_

- [x] 7.2 生成された enum 型を baseTypes に統合する
  - AutoGeneratedType（kind: Enum）を GraphQL スキーマ定義に変換する
  - 必要に応じて enum 値のリゾルバマッピングを生成する
  - _Requirements: 1.4, 2.4_

- [x] 8. Golden file テストを追加する

- [x] 8.2 (P) スキーマ外 TypeScript enum のテストケースを追加する
